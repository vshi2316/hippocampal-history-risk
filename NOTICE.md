# Reference assets and source attribution

The `resources/ST_to_Brain_Region_Mapping.csv` file is an anatomical field map
reformatted from the study's completed FreeSurfer mapping audit. It records anatomical labels and source fields. Released ADNI field dictionaries are read locally
to check the selected fields.

ENIGMA Toolbox assets are fetched from MICA-MNI/ENIGMA at commit
`b08974b55243060cbc1fad12c87048037446e8f7`. Files include the DK/aparc BigBrain
gradient, its ordered label table, fsaverage5 cortical surfaces and hemisphere
annotations. ENIGMA's own license and attribution apply to those assets.
The BigBrain microstructural-gradient reference is Paquola et al., PLoS Biology
2019, DOI 10.1371/journal.pbio.3000284. FreeSurfer surface and Desikan-Killiany
parcellation attribution remain applicable.

Access to ADNI, HABS-HD, OASIS-3 and MCSA data follows each cohort's terms.
