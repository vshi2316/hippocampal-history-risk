# Authorized local inputs

Place authorized cohort files in the subdirectories listed in
[input-files.tsv](../docs/input-files.tsv), or set `HIPPO_HISTORY_DATA` to an
equivalent directory. Keep the released filenames and archive members unchanged.
Obtain ADNI, HABS-HD, OASIS-3 and MCSA data through each study's access procedure.
The four cohorts retain their own identifiers and timelines.
